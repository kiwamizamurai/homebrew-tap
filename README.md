# homebrew-tap

🍺 Homebrew tap for kiwamizamurai's tools.

| Name | Install | What it is |
|---|---|---|
| [washi](https://github.com/kiwamizamurai/washi) | `brew install --cask kiwamizamurai/tap/washi` | A quiet viewer for Markdown, Typst, LaTeX, Mermaid and PDF (Apple Silicon macOS) |
| [ghif](https://github.com/kiwamizamurai/ghif) | `brew install kiwamizamurai/tap/ghif` | CLI tool to fetch GitHub issues and save them as Markdown files |
| [insomnim](https://github.com/kiwamizamurai/Insomnim) | `brew install kiwamizamurai/tap/insomnim` | macOS sleep-inhibitor CLI (Insomnia + Nim) using IOKit Power Management |
| [ossint](https://github.com/kiwamizamurai/ossint) | `brew install kiwamizamurai/tap/ossint` | A tool OSINT for Github OSS |

Homebrew only loads non-official taps you trust. Installing a fully qualified name, as in the commands above, trusts just that item. To install by short name, trust it first, for example `brew trust --cask kiwamizamurai/tap/washi`.

Update with `brew upgrade` (add `--cask` for washi).
